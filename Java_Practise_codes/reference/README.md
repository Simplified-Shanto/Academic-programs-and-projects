# Java PYQ Bank

The source question bank is stored at [Java_PYQ_Bank.pdf](./Java_PYQ_Bank.pdf).
It is a topic-organised collection of SUST CSE 233 Java past questions.

## Multithreading reference

The multithreading section is PDF pages 45–46, section 9. Its questions cover:

- ways to create threads and the benefits of multithreading;
- `join()`, thread-safe methods, and synchronization;
- deadlock and inter-thread communication;
- thread states;
- `wait()`, `notify()`, and `notifyAll()`;
- tracing the output of a program using `sleep()` and `join()`;
- producer-consumer coordination;
- combining `Thread`, `Runnable`, priorities, and delays.

The practice problems in [`../C11multithreading/PYQ_Exercises.md`](../C11multithreading/PYQ_Exercises.md)
are original exercises based on these topics and are linked to the demos in the
same folder.
